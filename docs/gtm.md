# Go-to-market — SlotWake München

Separate from fs-hilfe. Goal: validate notify-only waitlist demand.

**Live URL:** https://vodnik1974.github.io/slotwake-muenchen/

## Launch checklist

1. Open live URL — language toggle EN/DE works.
2. Submit one test form → check inbox for FormSubmit **activation** mail → click Confirm.
3. Submit a second test → should arrive as waitlist email.
4. Post with the live URL (see `posts.md`).

## Channels

### Day 1
- Reddit r/Munich (EN)
- Telegram / WhatsApp expat Munich groups (EN)
- Make it in Munich / Facebook expats (EN)

### Day 2–3
- r/germany or r/Expats_In_Germany (say Munich-only)
- DE Umzug München groups
- LinkedIn relocation / People Ops (optional)

### Day 7 — concierge
For first 10 with urgency `14d`:
1. Copy signups → `data/waitlist.csv`
2. Run `scripts/notify_once.py` morning + ~30 min before Bürgerbüro opening
3. Track: alerted / booked / no

**Go further if:** ≥3 real bookings from your alert **or** ≥50 emails in 2 weeks.
